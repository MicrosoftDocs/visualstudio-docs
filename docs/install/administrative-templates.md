# Visual Studio Administrative Templates (ADMX)

The Visual Studio ADMX and Group Policy guidance is now part of [Configure Visual Studio policies](configure-policies-for-enterprise-deployments.md#choose-a-policy-management-method). That article explains how to download and deploy the template, use the Intune settings catalog or imported ADMX, and configure the documented policy values.

For policy details, including installation, update, feedback, and survey settings, see [Configure Visual Studio policies](configure-policies-for-enterprise-deployments.md).

## Visual Studio policy categories

See the policy categories and feature-specific links in [Configure Visual Studio policies](configure-policies-for-enterprise-deployments.md#choose-a-policy-management-method).

## Acquiring the Visual Studio Administrative Template (ADMX)

Download the current [Visual Studio ADMX template](https://aka.ms/vs/admx/details).

## Deploying the policies

Follow the [policy deployment steps](configure-policies-for-enterprise-deployments.md#deploy-the-policies) for the Intune settings catalog, imported ADMX in Intune, Group Policy, Configuration Manager, or registry-based configuration.
