# What's new in Visual Studio docs

Welcome to what's new in Visual Studio docs. The following sections provide details on the previous three months of new and updated content.

## August 2026

### Extensibility

**Updated articles**

### IDE

**Updated articles**

- [Use code snippets in Visual Studio](../ide/code-snippets.md) - Restructure guidance for finding, inserting, customizing, troubleshooting, and safely reviewing code snippets.
- [Manage chat context in GitHub Copilot Chat](../ide/copilot-chat-context-references.md) - Clarify where context-window usage indicators appear across Visual Studio versions and chat surfaces.
- [Customize chat responses](../ide/copilot-chat-context.md) - Add organization-level custom-instruction behavior, review, and opt-out guidance.
- [Use custom agents in GitHub Copilot](../ide/copilot-specialized-agents.md) - Add organization-level custom-agent discovery, inspection, availability, and configuration guidance.
- [GitHub Copilot usage and models](../ide/copilot-usage-and-models.md) - Explain AI Credit calculation, plan limits, usage alerts, and the distinction between plan and context-window usage.

### MSBuild

**Updated articles**

- [Change waves](../msbuild/change-waves.md) - Document MSBuild 18.9/18.10 change waves and how to restart persistent build processes after changing feature-wave settings.
- [Common MSBuild Project Properties](../msbuild/common-msbuild-project-properties.md) - Add the `DeterministicTimestamp` property and clarify deterministic-build behavior.
- [MSBuild Server](../msbuild/msbuild-server.md) - Explain .NET 11 default enablement, node reuse, disabling, fallback conditions, and diagnostics for MSBuild Server.

**New articles**
